# 弈间 1.0.1

原生 macOS 中文离线棋类练习应用，支持国际象棋、中国象棋和围棋。

## 本次更新

- 三棋主题应用图标，包含国际象棋马、中国象棋将与围棋棋子。
- 整理使用指南、源码构建、贡献说明及开源许可。
- 安装包提供 SHA-256 校验文件。

## 已有功能

- 四档离线 AI，可选先手或后手；围棋支持 9／13／19 路。
- 三种棋的入门教程、测验与本地学习进度。
- 自动保存、棋谱库、逐手复盘、局面评估和建议着法。
- `.yijian` 完整棋谱导入导出；国际象棋 PGN、围棋 SGF 导出。

## 下载与安装

下载本页附件 `弈间-macOS-arm64.zip`，解压后将 `弈间.app` 拖到“应用程序”目录。安装包内已包含两个离线引擎，不需要额外下载。

发布包适用于 Apple Silicon，系统目标 macOS 13 及以上；实际验证环境为 macOS 27.0.1。当前包使用本机临时签名，未进行 Apple Developer ID 签名或公证。

## 校验

下载 `SHA256SUMS.txt`，与 ZIP 放在同一目录后运行：

```sh
shasum -a 256 -c SHA256SUMS.txt
```

## 使用范围与许可

AI 档位不等同于 Elo 或围棋段位。GNU Go 适合入门练习，复杂死活的自动判定可能有偏差。当前 PGN／SGF 仅支持导出。

项目采用 GPL-3.0-or-later；应用内附带第三方引擎对应版本的源码、补丁、重建脚本及许可证。
