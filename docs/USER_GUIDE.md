# 使用指南

[返回项目首页](../README.md)

## 开始对弈

1. 点击“新对局”，选择国际象棋、中国象棋或围棋。
2. 选择启蒙、入门、进阶或挑战档位，再选择先手或后手。围棋可选 9／13／19 路。
3. 点击“摆好棋盘，开始”。选择后手时，AI 会先落子。

国际象棋和中国象棋先点己方棋子，再点合法目标；国际象棋兵到达底线时会出现升变选择。围棋直接点击交叉点，禁止占用、无气自杀及重复局面的落子。

点击灯泡按钮可查看建议。“悔棋”会另存练习分支，原始棋谱保留在棋谱库。围棋可“停一手”；双方连续停着后，程序估计死活并按当前棋盘数子。

## 入门学堂

每种棋有 3 课。阅读各节说明，回答小测验后完成课程。学习进度保存在本机，重启应用后仍可查看。

## 复盘与继续对弈

1. 在当前棋局点击“复盘”，或从“我的棋谱”打开已有记录。
2. 点击着法、拖动进度条，或使用左右方向键逐手回看。
3. 点击“分析当前局面”获取评估和建议着法；已分析的局面会记录在评估轨迹中。
4. 未结束的棋局可点击“继续对弈”，从最后一手恢复。

国际象棋与中国象棋显示兵值或将杀距离；围棋显示含贴目的形势估计。这些数值不等同于胜率。

## 保存、导入与导出

每手棋后自动保存，也可点击“保存”。启动时恢复最近未结束的对局。

| 格式 | 导出 | 导入并继续 | 内容 |
|---|---|---|---|
| `.yijian` | 三种棋均支持 | 支持 | 完整对局、局面快照及已保存的复盘分析 |
| `.pgn` | 国际象棋 | 暂不支持 | 标准国际象棋记谱 |
| `.sgf` | 围棋 | 暂不支持 | 棋盘大小、贴目、棋手、着法及结果 |

棋谱位于：

```text
~/Library/Application Support/Yijian/Games/
```

每份棋谱独立存储，使用原子文件替换。学习进度保存在应用偏好设置中。迁移到另一台 Mac 时，使用 `.yijian` 导出与导入功能。

## 难度与规则范围

| 档位 | Fairy-Stockfish Skill Level | 单次思考时间 | GNU Go level |
|---|---:|---:|---:|
| 启蒙 | -20 | 180 ms | 0 |
| 入门 | -5 | 350 ms | 2 |
| 进阶 | 6 | 700 ms | 5 |
| 挑战 | 20 | 1500 ms | 10 |

这些档位没有经过 Elo 或围棋段位校准。GNU Go 是传统围棋程序，适合入门练习；19 路高难度可能思考较久。遇到引擎超时时，已完成的落子仍有保存，可点击重试。

国际象棋与中国象棋的走法和终局由 Fairy-Stockfish 判断。练习中自动接受引擎的可申和条件，例如国际象棋的三次重复和五十步规则。中国象棋长将长捉按内置引擎的规则裁定，不覆盖所有赛事规则版本。

围棋采用中国数子规则、白贴 7.5 与全局同形限制。连续两次停着后，由 GNU Go 估计死子，再对当前棋盘数子。复杂死活的自动判断可能不准确，计分功能用于练习。

## 常见问题

**应用是否需要联网？**

已打包的应用不需要。只有首次从源码构建时，脚本需要下载固定版本引擎源码。

**为什么打不开 PGN／SGF？**

当前版本只导入 `.yijian`。PGN 和 SGF 用于向其他棋类软件导出。

**下载的应用是否经过公证？**

当前包使用本机临时签名，未进行 Developer ID 签名及 Apple 公证。macOS 可能限制从互联网下载的未公证应用；源码构建方法见[构建说明](BUILDING.md)。
